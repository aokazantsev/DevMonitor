# Сторонние компоненты

DevMonitor распространяется под лицензией MIT. В папке `lib\` и в установщике лежат чужие
компоненты под своими лицензиями — без изменений, как их публикуют авторы.

| Компонент | Версия | Лицензия | Исходники |

| HidSharp | 2.6.4 | Apache-2.0 | https://github.com/IntergatedCircuits/HidSharp |
| BlackSharp.Core | 1.0.7 | MPL-2.0 | https://github.com/Blacktempel/BlackSharp |
| DiskInfoToolkit | 1.1.2 | MPL-2.0 | https://github.com/Blacktempel/DiskInfoToolkit |
| RAMSPDToolkit-NDD | 1.4.2 | MPL-2.0 | https://github.com/Blacktempel/RAMSPDToolkit |
| System.Buffers, System.Memory, System.Numerics.Vectors, System.Runtime.CompilerServices.Unsafe, System.CodeDom, System.Management, System.Security.AccessControl, System.Security.Principal.Windows, System.Threading.AccessControl | см. сборки | MIT | https://github.com/dotnet/runtime |
| PawnIO (установщик драйвера; скачивается при сборке, в git не хранится, ставится отдельной программой) | 2.2.0 | GPL-2.0 (драйвер) | https://github.com/namazso/PawnIO, https://github.com/namazso/PawnIO.Setup |
